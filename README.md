# 🐂 FODEGAN - Fondo de Inversiones Ganadero

## 📖 Descripción del Proyecto
FODEGAN es una plataforma web integral diseñada para conectar inversionistas con propietarios de fincas ganaderas certificadas. El sistema permite financiar ciclos de engorde y ceba, brindando trazabilidad, seguridad y rentabilidad transparente para ambas partes. Este repositorio contiene el Producto Mínimo Viable (MVP) enfocado en la interfaz de usuario y la experiencia de inversión.

## 💻 Tecnologías Usadas (Stack)
La arquitectura del proyecto está basada en el patrón **MVC** (Modelo-Vista-Controlador), utilizando el siguiente stack tecnológico:
* **Frontend:** Vue.js 3 (Composition API) + CSS3 moderno.
* **Backend:** Node.js con Express *(Fase de planificación)*.
* **Base de Datos:** SQL **
